# Volt Design System

Bestehende Identität: Hintergrund #0B0B0F, Surface #1A1C23, Primary #90D5FF, Text #F4F5F7, Muted #8A8D9F, Border #2A2B31, Accent #FF3366. Space Grotesk für Überschriften/Zahlen; Manrope für Text. Spacing 4/8/16/24/32/48; Radien 8/12/16/full. packages/ui bleibt Quelle.

Ziel: semantische Success/Warning/Danger/Focus/Disabled-Tokens. 44 pt/48 dp Touchflächen, klare Accessibility-Namen, Dynamic Type, kontrastreiche Zahlen und textliche Chartzusammenfassungen. Kg/Reps zuerst; RPE/RIR optional. Fehler direkt am Eingabefeld, Daten nie bei Fehler verwerfen. Ein Sheet-/Dialogvertrag, dezente Haptics, Reduce Motion. Keine neue Animation ohne Nutzwert. Light Theme ist späteres bewusstes Feature.
