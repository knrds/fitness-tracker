Vollständiger Lizenztext liegt in LICENSE. Abgerufen am 12.09.2026; upstream main: 15df9e2dbc621450001960bed5a30e6a75357faa. Anpassungen: lokaler Datenvertrag, Formatierung; Rendering und Zuordnung zu Volt-Muskelgruppen in AnatomyFigure.tsx. Keine zusätzliche Laufzeitabhängigkeit installiert.

Die Abbildung illustriert Muskelregionen; sie ist keine individuelle Körpervermessung. Trainingsfarben zeigen die in der App erfassten Arbeitssätze. Bei Umfangsmessungen zeigen Farben Auswahl bzw. vorhandene Eingaben, keine Gesundheitsbewertung.
