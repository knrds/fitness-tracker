# Agent Briefings

This directory holds briefing documents and prompt templates for AI agents
working on this codebase.

## Structure

| File            | Purpose                                          |
| --------------- | ------------------------------------------------ |
| `mobile-dev.md` | Briefing for agents working on `apps/mobile`     |
| `domain.md`     | Briefing for agents working on `packages/domain` |

## Guidelines for Writing Briefings

- State the scope clearly (which package, which feature)
- Link to relevant types in `packages/domain`
- Include constraints (no new dependencies without discussion, etc.)
- List acceptance criteria
